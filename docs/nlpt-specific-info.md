# specific info for NLPT events

## NLPT-SSO

Einfach aktivieren und die Vorschläge des frontend übernehmen, lediglich das Eventjahr muss angepasst werden.

**SSO Login URL:** `https://nlpt.online/app/event-login?redirect=`  
**SSO Onboarding URL:** `https://nlpt.online/api/onboarding/2024`

> [!NOTE]
> Es muss nirgends ein Token oder sowas eingetragen werden, einfach die URLs so wie oben angegeben nutzen
